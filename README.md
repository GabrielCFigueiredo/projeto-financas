# 💰 Financial Control API

API de controle financeiro desenvolvida com FastAPI.

## 🚀 Tecnologias

- FastAPI
- SQLAlchemy
- SQLite
- JWT Authentication
- Matplotlib

## 📊 Funcionalidades

✔ CRUD de transações financeiras  
✔ Relatórios financeiros  
✔ Gráficos de receitas e despesas  
✔ Autenticação JWT  
✔ Dashboard financeiro por usuário  

## 🔐 Autenticação

Sistema de login com JSON Web Token para proteger rotas.

## 🗄 Banco de dados

Utiliza SQLite com ORM SQLAlchemy.

## ▶ Como rodar o projeto

pip install -r requirements.txt
uvicorn api:app --reload
